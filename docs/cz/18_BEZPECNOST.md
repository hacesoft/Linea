# Bezpečnost a odpovědnost

LINEA aktivně řídí energetický systém. Chybný registr, znaménko, datový typ nebo limit může způsobit nežádoucí tok energie.

Před použitím ověřte konkrétní hardware, firmware, registry, limity distributora a bezpečnostní rezervy. Současně smí Grid Point aktivně řídit pouze jeden controller.

## Zřeknutí se odpovědnosti

Projekt je poskytován bez záruky správnosti, spolehlivosti, funkčnosti nebo vhodnosti pro konkrétní účel. Použití softwaru, kódu, schémat a technických postupů je na odpovědnost uživatele.

Autor nenese odpovědnost za škody, ztráty, výpadky, poškození zařízení, ztrátu dat, finanční škody ani jiné následky způsobené použitím projektu.

Uživatel odpovídá za ověření souladu instalace s platnými technickými, bezpečnostními a právními požadavky.
