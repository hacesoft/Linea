# Pravidla dokumentace LINEA

Technická dokumentace vždy popisuje aktuální stav projektu.

Historie implementace patří pouze do `CHANGELOG.md`.

Při psaní funkce se používá tato struktura:

1. účel;
2. vstupy a jednotky;
3. výpočet nebo rozhodovací podmínky;
4. výstup;
5. vazby na další části;
6. bezpečnostní/fail-safe chování.

Nepoužívají se formulace typu „při auditu“, „původně“, „po opravě“ nebo porovnávání s předchozí verzí, pokud nejde o CHANGELOG.
