# API examples

These demonstration responses were generated by running the reference API functions with synthetic inputs. They are not installation measurements.

- [health.json](../../examples/health.json)
- [status.json](../../examples/status.json)
- [health-initializing.json](../../examples/health-initializing.json)
- [status-initializing.json](../../examples/status-initializing.json)

```bash
curl -i 'http://LINEA_HOST:1880/api/v1/health'
curl -i 'http://LINEA_HOST:1880/api/v1/status'
```

Successful status includes `units` and schema 1. For HTTP 503 handle `status: "initializing"`; do not dereference a missing `system`. Check freshness even after HTTP 200. Do not infer module age from the main snapshot when module timestamps are missing.
